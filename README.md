# ProjetoAW2

Onde se passa a história

A história se passa em uma escola técnica muito parecida com a realidade que conhecemos. O ambiente é cotidiano, mas apresentado de forma exagerada e cômica, transformando uma simples tarefa escolar em uma verdadeira jornada de aventura.

Início

Os cinco amigos — Jofrey Gineco, Maite Julho, Louro Riacho, Joel Pedra e Câimbra Vitrola — chegam para mais um dia normal de aula. Porém, eles percebem que precisam encontrar um lugar adequado para realizar o trabalho de Edinson Https.

Enquanto procuram pela escola, encontram uma sala desbloqueada e decidem começar por ali. O que parecia ser apenas uma solução temporária acaba dando início a uma jornada muito maior do que imaginavam.

Meio

Ao explorar diferentes salas da escola, o grupo encontra uma série de puzzles, charadas, objetos e desafios deixados pelos professores, como a Fé de Nanda.

Para continuar avançando, os amigos precisam explorar os ambientes, encontrar itens e descobrir como desbloquear novas salas. Cada espaço apresenta um novo desafio e contribui para que o grupo se aproxime cada vez mais de seu objetivo.

O que deveria ser apenas uma tarefa escolar começa a se transformar em uma verdadeira aventura pelo campus.

Fim

Depois de superar os desafios e encontrar todos os objetos necessários, o grupo finalmente chega à última sala.

Lá, eles utilizam tudo o que encontraram durante a jornada para concluir a tarefa de Edinson Https. Após tantos obstáculos, finalmente conseguem realizar o trabalho e alcançar seu objetivo.

Resumo da história

Em uma escola técnica aparentemente comum, cinco amigos precisam encontrar uma sala onde possam realizar um trabalho escolar. O que começa como uma simples busca rapidamente se transforma em uma aventura cheia de puzzles, charadas, objetos misteriosos e desafios espalhados pelo campus.

Para concluir o trabalho de Edinson Https, o grupo precisará explorar as salas, superar os obstáculos e descobrir os segredos deixados pelos professores. Depois de uma longa jornada, os cinco finalmente chegam à sala final e conseguem concluir a tarefa.
